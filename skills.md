# Skills & Tech Stack

## Programming Language
- **TypeScript**: Strict mode enabled.
- **Node.js**: Runtime environment.

## AI & NLP
- **LangChain.js** (`@langchain/core`): For agent orchestration, prompt templates, and chain definitions.
- **Google GenAI** (`@langchain/google-genai`): Standard LLM provider integration.
- **Embeddings**: Google Generative AI Embeddings.
- **Vector Store**: `hnswlib-node` - A fast, local vector database perfect for Node.js to store schema embeddings.

## Database
- **MySQL2** (`mysql2` / `mysql2/promise`): For querying the MySQL database securely.

## Interfaces
- **Express.js**: For building the REST API server.
- **Commander.js**: For building the CLI tool.

## Utilities
- **dotenv**: Environment variable management.
- **csv-stringify**: For generating CSV output if required.
- **console.table**: For tabular CLI output.
